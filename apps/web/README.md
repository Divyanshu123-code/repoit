# Web Application (`apps/web`)

React + TypeScript web frontend built with Vite and TanStack Query.

## Responsibilities
- **Repository Overview**: File tree explorer, language statistics, and scan run status.
- **Semantic Search & Chat**: RAG assistant interface with expandable evidence and citation panels (file paths + line ranges).
- **Risk Table**: Defect prediction risk probabilities, risk bands, model versions, and contributing metrics.
- **Static Findings**: Ruff static analysis findings categorized by severity and rule with triage filtering.
- **Dependency & Impact Graph**: Interactive graph visualization of module dependencies and reverse reachability / change-impact analysis.
